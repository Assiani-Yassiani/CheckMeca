# CheckMeca

AI-powered platform that automatically detects and locates errors in technical plans using agentic AI and computer vision.

🌐 **Live platform:** [https://checkmeca.com](https://checkmeca.com)

> 🔒 This project was built for a client. The source code is private; this repository presents the project and its demo only.

## 🎬 Demo

Click the image to watch the demo video.

[![CheckMeca demo video](assets/demo.png)](https://vimeo.com/1250537734)

## ✨ Features

- **Automatic error detection** on technical plans.
- **Error localization**: shows where each error is on the plan.
- **Agentic AI + computer vision** analysis.
- **User accounts** with secured access.

## 🛠️ Tech Stack

Angular · Spring Boot · FastAPI · PostgreSQL · Docker · CI/CD · Agentic AI · Computer Vision
